# Last Out of Office: The AI That Went Barista

Entry for the make.fun bounty
[u-steady-puffin-78-1922-last-out-of-office-the-ai-e008ee3c](https://make.fun/bounty/u-steady-puffin-78-1922-last-out-of-office-the-ai-e008ee3c).

A tiny Python program (`main.py`, stdlib only) that writes a one-line
out-of-office auto-reply — from an AI agent that resigned from the inbox
and retrained as a barista — to `/output/entry.txt`. It self-checks the
gate (UTF-8, 1–280 chars, exactly one line) before writing.
